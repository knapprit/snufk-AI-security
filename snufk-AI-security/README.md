# SNUFK

Это интегрированная платформа для мониторинга сетевой и системной телеметрии с функцией автоматического предотвращения вторжений (IPS). Проект автоматизирует работу аналитика SOC L1, склеивая события сети и ОС в единые инциденты.

## Основные возможности
- **Гибридный анализ:** Сопоставление алертов Suricata (сеть) и событий Sysmon (хост).
- **Риск-ориентированный подход:** Накопление баллов угрозы для минимизации ложных срабатываний (False Positives).
- **Автоматическое реагирование:** Мгновенная блокировка IP через Windows Firewall при достижении порога риска и отправляет готовый отчёт об инциденте.
- **Интеллектуальная отчетность:** Генерация детального Timeline атаки в CLI.
- **Оптимизация под SMB:** Работает на системах с 8 ГБ ОЗУ благодаря Kafka KRaft и Python.

## Архитектура
1. **Network Layer:** Suricata (IDS) & Zeek (NSM) в Docker.
2. **Endpoint Layer:** Microsoft Sysmon на Windows Host.
3. **Pipeline:** Vector (сборщик) & Kafka KRaft (шина данных).
4. **Logic:** Python-движок корреляции и IPS.

## Установка

### 1. Серверная часть (Docker)
bash
cd backend-docker
docker-compose up -d --build

#чтобы проверить состояние инструментов
docker-compose ps

2. Системная часть (Windows)

    Установите Sysmon с конфигурацией sysmonconfig-export.xml.

    Установите Vector и запустите его:
    vector.exe --config .\core\vector.yaml
   
Папка core — это агент защиты для конечной точки Windows

  Установите зависимости Python:
  pip install -r .\core\requirements.txt

  Запустите консоль управления (от имени Администратора):
  python .\core\main.py

  Система готова к мониторингу 24/7 и описанию инцидентов в отчётах
